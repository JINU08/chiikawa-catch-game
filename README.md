# 🌸 치이카와 잡기! (Chiikawa Catch Game)

귀엽고 사랑스러운 치이카와 친구들과 함께하는 **2D 캐주얼 아케이드 웹 게임**입니다!  
치이카와(10점), 하치와레(20점), 우사기(50점)가 구멍에서 쏙쏙 튀어나오면 뿅망치로 콕콕 터치하여 최고 점수에 도전해보세요!

---

## 🌟 주요 특징 및 차등 점수 시스템

### 1. 캐릭터별 차등 점수 & 출현 확률
| 캐릭터 | 외형 특징 | 획득 점수 | 등장 확률 | 체류 시간 특징 |
| :---: | :--- | :---: | :---: | :--- |
| **🤍 치이카와** | 순백색 둥근 몸체, 순둥한 처진 눈썹, 핑크 볼터치 | **+10점** | **60%** | 가장 자주 등장하며 화면에 오래 머무름 |
| **💙 하치와레** | 푸른 5:5 가르마 헤어, 뾰족 고양이 귀, 당찬 미소 | **+20점** | **30%** | 보통 빈도로 등장하며 중간 속도로 사라짐 |
| **💛 우사기** | 파스텔 레몬 옐로우, 길쭉한 토끼 귀, 장난기 넘치는 눈망울 | **+50점** | **10%** | 가장 드물게 등장하며 번개처럼 짧게 머묾! |

- **시각 효과**: 캐릭터별 점수에 맞춰 타격 위치에 **`+10점!`**, **`+20점!`**, **`+50점!`** 텍스트 및 전용 스파크(우사기는 찬란한 골드 스파크)가 팡 터집니다.
- **중복 클릭 방지**: 한 번 타격된 캐릭터는 즉시 판정 완료되어 연타해도 점수가 중복으로 가산되지 않습니다.

---

### 2. 3단계 난이도 시스템 (난이도별 최고점수 개별 저장)
- 🌱 **쉬움 (45초)**: 초보자도 잡기 쉽게 캐릭터가 화면에 오래 나타나며 여유로운 플레이 가능
- ⭐ **보통 (30초)**: 기본 등장 속도와 표준 스릴감 제공
- 🔥 **어려움 (30초)**: 캐릭터가 빠르게 나타났다 사라지며, 2마리 동시 출현 빈도가 높아 최고 수준의 반응속도 요구!
- **우사기 보너스**: 모든 난이도에서 우사기는 다른 캐릭터보다 체류 시간이 훨씬 짧아 높은 집중력을 요합니다.
- **난이도별 최고 점수**: 쉬움, 보통, 어려움 각각의 최고 점수가 브라우저 `localStorage`에 개별 저장됩니다.

---

### 3. 화면 구성 및 편의 기능
- **게임 화면 하단 점수표**: 각 캐릭터의 미니 일러스트, 이름, 획득 점수(+10/+20/+50), 출현 정보가 깔끔한 카드 형태로 상시 표시됩니다.
- **게임 종료 모달 & 세부 통계**: 플레이한 난이도, 최종 점수, 그리고 잡은 캐릭터별 포획 마리수 및 점수 내역(치이카와 N마리, 하치와레 N마리, 우사기 N마리)을 상세하게 분석해 보여줍니다.
- **사운드 효과 (Web Audio API)**: 외부 오디오 파일 없이 브라우저 내장 합성기로 경쾌한 타격음, 우사기 전용 챠랑음, 카운트다운 비프, 팡파레를 재생합니다 (소리 켜기/끄기 토글 지원).

## 🚀 실행 방법

### 방법 1. 가장 간편한 방법 (파일 직접 열기)
1. 탐색기에서 `d:\천수폴더\12_UI제작\duthejijapgi` 폴더로 이동합니다.

### 방법 2. 로컬 웹 서버로 열기 (권장)
현재 로컬 서버가 포트 3000에서 실행 중입니다:
- 웹 브라우저 주소창에 `http://localhost:3000` 을 입력하여 접속합니다.
- 서버를 나중에 직접 다시 실행하려면 터미널에서 다음 명령어를 실행하세요:
  ```bash
  node server.js
  ```
