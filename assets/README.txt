# 치이카와 커스텀 이미지 안내

이 폴더(assets/)에 직접 소장하고 계신 캐릭터 이미지를 넣어 사용할 수 있습니다!

1. 추천 이미지 파일 이름:
   - chiikawa.png (치이카와 이미지)
   - hachiware.png (하치와레 이미지)
   - usagi.png (우사기 이미지)

2. 권장 사양:
   - 배경이 투명한 PNG 또는 WebP 파일
   - 정사각형 비율 (예: 256x256 또는 512x512)

3. 현재 기본 설정:
   - 이미지 파일이 없어도 고품질 내장 SVG 그래픽으로 치이카와(흰색), 하치와레(파란색), 우사기(노란색)가 완벽하게 표현됩니다.
   - 나만의 이미지를 적용하고 싶을 때는 game.js의 `USE_CUSTOM_IMAGES = true;` 옵션을 활성화하시면 됩니다.
